## 🔍 Overview

This repository demonstrates how to build a production-ready CRUD (Create, Read, Update, Delete) API using FastAPI. It showcases FastAPI's async capabilities, automatic validation, and interactive documentation features.

## ✨ Features

| Feature | Description |
|---------|-------------|
| **Async/Await** | Fully asynchronous operations for high performance |
| **Auto Documentation** | Swagger UI & ReDoc generated automatically |
| **Data Validation** | Request/response validation with Pydantic |
| **Type Safety** | Full Python type hints throughout |
| **Dependency Injection** | Clean, reusable components |
| **Error Handling** | Consistent HTTP error responses |
| **Pagination** | Built-in pagination for list endpoints |
| **CORS Support** | Cross-Origin Resource Sharing enabled |

## 🛠️ Tech Stack

- **Framework:** FastAPI
- **Server:** Uvicorn (ASGI)
- **Database:** SQLite with async SQLAlchemy
- **Validation:** Pydantic v2
- **Python:** 3.9+
